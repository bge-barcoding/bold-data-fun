# What it does
Takes a folder of log files from the manual curation tool and maps them against a BOLD data package to extract the columns needed by CBG staff to action the updates in BOLD.

## input
1. path to a folder of log files in format "curator name_other stuff.log" e.g. "Dapporto_Pieridae.log"
2. path to the bold data package in TSV format
3. path to a folder for output files
4. your initials, e.g. "BP"

## output
1. tsv files with columns extracted from bold data package and updates from manual curation tool applied
2. summary
